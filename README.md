# Customer Shopping Behavior Analysis using Python

## Project Overview
This project focuses on analyzing customer shopping behavior using Exploratory Data Analysis (EDA) in Python. The main objective is to understand customer preferences, purchasing patterns, spending habits, and payment methods through data analysis and visualization.

## Dataset Information
- **Dataset:** Shopping Trends Dataset
- **Total Records:** 3,900
- **Total Columns:** 19
- **Missing Values:** 0
- **Duplicate Records:** 0

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

1. Data Loading
2. Data Understanding
3. Data Inspection
4. Data Cleaning and Validation
5. Exploratory Data Analysis (EDA)
6. Data Visualization
7. Business Insights and Recommendations

### Multivariate Analysis

## Key Findings

- Clothing is the most purchased category with 1,737 records.
- Accessories is the second most purchased category with 1,240 records.
- The average purchase amount is approximately $59.76.
- Credit Card is the most frequently used payment method.
- Shopping activity is almost equally distributed across all four seasons.
- The numerical variables show very weak linear correlations.

## Business Recommendations

- Focus on popular product categories.
- Maintain sufficient stock of frequently purchased items.
- Develop targeted marketing campaigns.
- Introduce seasonal promotions.
- Encourage customer subscriptions through loyalty benefits.
- Support multiple convenient payment methods.
